# HariMultiThread 2.0 Changelog

## 2.0.1

- Register the bundled LWJGL core module alongside Vulkan so Forge can resolve the Jar-in-Jar dependencies on a dedicated server.
- Keep the Forge descriptor aligned with the GPL-3.0-only source license and include the complete license text in the release JAR.
- Point the Forge descriptor to the public source repository.
- Verified dedicated-server startup with Forge 47.4.16 on Minecraft 1.20.1. Client launch has not been verified.
